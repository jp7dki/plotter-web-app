# プロッタ千里ちゃん

**Plotter Senri-chan** — a pen plotter studio in your browser

ブラウザだけで動く、ペンプロッタ用の作図・描画アプリです。
カメラで撮った写真を線画の似顔絵にしたり、QRコード・文字・アイコン・SVG・G-code を組み合わせたりして、そのまま grblHAL のプロッタへ送って描けます。

**▶ アプリを開く：https://jp7dki.github.io/plotter-web-app/**

HTML ファイル1つだけで動きます。インストールやサーバーは不要です。

## できること

- **似顔絵**：カメラや画像ファイルから線画を作ります（FDoG / DoG / Canny、陰影ハッチング、プリセット）
- **QRコード**：アプリ内で生成し、ペンで塗れる線に変換します（2種類の塗り方を比較可能。読み取りテスト付き）
- **手書き**：プレビューの紙にマウスやペン、指で直接描けます（全画面表示・手ぶれ補正・直線・消しゴム・元に戻す）
- **文字**：PC に入っている書体を使って、一筆書き風・袋文字・塗りつぶしで描きます
- **アイコン**：ハート・星・吹き出しなど16種類。回転・塗り・「下の線を消す」に対応しています
- **SVG / G-code の読み込み**：複数のファイルを読み込めます。G-code は「ファイルのまま送信」と「現在の設定で作り直す」を選べます
- **エレメント（レイヤー）編集**：表示・非表示、重なり順、複製、削除。プレビュー上でドラッグして移動・拡大縮小できます
- **用紙**：名刺・ハガキ・A5・A4・カスタム、縦長・横長。プロッタのストロークに合わせて 90° 回転して出力できます
- **プロッタ操作（Web Serial）**：
  - 描画の開始・一時停止・中止
  - 手動移動（ジョグ）と原点合わせ
  - サーボのペン位置調整
  - grblHAL 設定（`$$`）の読み込み・書き込み（日本語の説明付き）
- **描き順**：なるべく一筆書きで描き、ペンの上げ下げを減らします（標準／一筆書き優先／描いた線をなぞって移動 から選択）
- **出力**：G-code 保存、SVG 保存
- **設定プロファイル**：用紙・ペン・速度・G-code の設定を名前を付けて保存・切り替えできます

## 使い方

1. Chrome または Edge で [アプリ](https://jp7dki.github.io/plotter-web-app/) を開きます。
   - 手元で使う場合は `index.html` を直接開くか、次のコマンドで配信してください。

     ```bash
     python3 -m http.server 8765 --bind 127.0.0.1
     ```

2. 左の「エレメント」で、描くもの（似顔絵・QR・文字・アイコン・SVG・G-code）を追加します。
3. 右の「用紙・プロッタの範囲」と「ペン」を、お使いの機械に合わせます。
4. 「プロッタ接続」で USB 接続し、「枠をなぞる」で範囲を確かめてから「▶ 描画開始」を押します。

## 動作環境

- **ブラウザ**：Chrome / Edge（Web Serial API を使うため）
- **プロッタ**：grblHAL（GRBL 互換）。ペンの上げ下げは、スピンドル PWM のサーボ（`M3S…` / `M5`）か Z 軸で行います。

### grblHAL 設定のヒント

| 設定 | 推奨 | 理由 |
|---|---|---|
| `$32` | `0` | レーザーモードを切る。オンだと G0 での移動中にサーボのペンが動いてしまう |
| `$1` | `255` | 止まっている間もモーターを保持し、ペンの上げ下げの反動による位置ずれを防ぐ |
| `$120` / `$121` | 機械に合わせて調整 | 加速度。小型機で脱調するときは下げる |
| `$22` / `$20` / `$21` | `0` | リミットスイッチがない機械では、ホーミング・リミットを切る |

## プライバシー

- 写真・QR の内容・読み込んだファイルは、すべてブラウザの中だけで処理します。外部には送信しません。
- ページの Content-Security-Policy で外部への通信を禁止しています。万一の通信の試みも、ブラウザが遮断します。
- 写真は保存しません。「線画を確定」すると破棄できます。
